# Distributed File System

We have a client file system, and its networking layer.
We also have a file server, and its networking layer.
The file server is connected to the disks, and the client networking layer is connected to the server networking layer.

On the client side, there are apps which access files and directories through its FS. The apps issue normal sys calls. Thus DFS is transparent.

When the client does a read() $\Rightarrow$ Req to File Server to read the block $\Rightarrow$ Res back via the network, where the client can also cache it, avoiding future calls for the same block.
